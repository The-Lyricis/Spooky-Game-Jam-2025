# 场景切换测试清单 ✅

## 📋 准备工作

### 1️⃣ 创建 GameConfig 资产
- [ ] 在 Project 窗口：`右键 > Create > SpookyGame > Game Config`
- [ ] 命名为 `GameConfig`，放在 `Assets/Resources/` 下

### 2️⃣ 配置 GameConfig
在 Inspector 中设置：
```
Scene Names
├─ Main Menu Scene Name: "MainMenu"  ← 你的主菜单场景名
└─ Game Scene Name: "Scene_0"        ← 你的游戏场景名（根据你的项目结构）

Stage Configuration
├─ First Stage Id: "D1"
└─ Stages (Size: 1)  ← 先配置一个测试
    └─ [0]
        ├─ Stage Id: "D1"
        ├─ Display Name: "DAY 1"
        ├─ Intertitle: "DAY 1 · 第一天"
        └─ Initial Flags: (Empty)

Transition Settings
├─ Default Fade Duration: 1.0
└─ Intertitle Duration: 2.0

Game Settings
├─ Use Main Menu: ✓ (勾选)
└─ Show First Stage Title: ✓ (勾选)
```

## 🎯 主菜单场景配置

### 场景名称
确认你的主菜单场景名称，应该是以下之一：
- `MainMenu`
- `Scene_MainMenu`
- 其他（请记下来）

### 场景层级结构
```
MainMenu Scene
├─ Canvas
│   └─ MainMenu (GameObject)
│       └─ MainMenu.cs (挂载脚本)
│       └─ Button - Start Game  ← 你创建的按钮
├─ Bootstrap (GameObject)
│   └─ Bootstrap.cs
├─ FadeScreen (Canvas)
│   └─ FadeScreen.cs
└─ EventSystem
```

### MainMenu GameObject 配置
- [ ] 挂载 `MainMenu.cs` 脚本
- [ ] **Start Button** 字段：拖入你创建的按钮
- [ ] **Game Config** 字段：拖入 `GameConfig.asset`

### Bootstrap GameObject 配置
- [ ] 挂载 `Bootstrap.cs` 脚本
- [ ] **Game Config** 字段：拖入 `GameConfig.asset`
- [ ] **Show Debug Info**：勾选（方便查看日志）

### FadeScreen 配置（如果还没创建）
创建一个新的 Canvas：
```
Hierarchy > 右键 > UI > Canvas
重命名为 "FadeScreen"
├─ Canvas
│   ├─ Render Mode: Screen Space - Overlay
│   └─ Sort Order: 999  ← 确保在最上层
└─ Panel (黑色背景)
    ├─ Image: 纯黑色
    ├─ CanvasGroup: Alpha = 0
    └─ Text (可选，用于显示 Intertitle)
```

挂载 `FadeScreen.cs` 到 Canvas 上，并配置：
- [ ] **Fade Panel**：拖入 CanvasGroup
- [ ] **Intertitle Text**：拖入 Text（可选）

## 🎮 游戏场景配置

### 场景名称
确认你的游戏场景名称：
- `Scene_0` ✅（根据你的项目结构）

### 场景层级结构
```
Scene_0
├─ Shared
│   ├─ Bootstrap
│   │   └─ Bootstrap.cs
│   ├─ Main Camera
│   ├─ Interactor
│   │   └─ Interactor.cs
│   ├─ UI_Root
│   │   └─ PromptUI.cs
│   └─ FadeScreen
│       └─ FadeScreen.cs
├─ Stage_D1  ← 你的第一关根节点
│   ├─ Background
│   ├─ 可交互物体（Say.cs 等）
│   └─ ...
├─ Stage_D2  ← 其他关卡（暂时禁用）
└─ Stage_D3
```

### Shared/Bootstrap 配置
- [ ] 挂载 `Bootstrap.cs` 脚本
- [ ] **Game Config** 字段：拖入 `GameConfig.asset`
- [ ] **Show Debug Info**：勾选

### Stage_D1 配置
- [ ] 确保 GameObject 名称为 `Stage_D1`
- [ ] 初始状态：**禁用**（Bootstrap 会自动启用）
- [ ] 在下面放置你的关卡内容（背景、可交互物体等）

---

## 🔧 Build Settings 配置

### 添加场景到 Build Settings
- [ ] `File > Build Settings`
- [ ] 将以下场景按顺序拖入：
  ```
  [0] MainMenu
  [1] Scene_0
  ```

⚠️ **重要**：如果场景不在 Build Settings 中，`SceneManager.LoadScene()` 会失败！

## 🐛 常见问题排查

### ❌ 点击按钮没有反应
**检查项**：
- [ ] `MainMenu.cs` 是否挂载到正确的 GameObject 上
- [ ] `Start Button` 字段是否已赋值
- [ ] 按钮是否有 `Button` 组件
- [ ] Console 是否有报错

### ❌ 报错：GameConfig is not assigned
**解决方法**：
- [ ] 在 `MainMenu` GameObject 的 Inspector 中
- [ ] 将 `GameConfig.asset` 拖到 `Game Config` 字段

### ❌ 报错：Scene 'Scene_0' couldn't be loaded
**解决方法**：
- [ ] 打开 `File > Build Settings`
- [ ] 将 `Scene_0` 场景拖入列表
- [ ] 或者在 `GameConfig` 中修改 `Game Scene Name` 为正确的场景名

### ❌ 场景加载后黑屏
**检查项**：
- [ ] `Scene_0` 中是否有 `FadeScreen` Canvas
- [ ] `FadeScreen.cs` 是否正确挂载和配置
- [ ] `EventBus` 是否正确订阅了 `FadeStartedEvent`

### ❌ Stage_D1 没有被激活
**检查项**：
- [ ] `Scene_0` 中是否有名为 `Stage_D1` 的根 GameObject
- [ ] `GameConfig` 中的 `First Stage Id` 是否为 `"D1"`
- [ ] Console 是否有 `[SceneService] Stage D1 not found!` 的报错

### ❌ Console 报错：NullReferenceException
**常见原因**：
- [ ] `Bootstrap.cs` 中的 `gameConfig` 未赋值
- [ ] `FadeScreen` 相关组件未正确配置
- [ ] `EventBus` 未初始化
