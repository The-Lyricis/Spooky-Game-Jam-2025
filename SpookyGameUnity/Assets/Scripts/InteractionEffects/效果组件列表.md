# 交互效果组件完整列表

## 📋 核心组件

### CompositeInteractable
**位置：** `World/CompositeInteractable.cs`  
**功能：** 可组合的交互对象基类  
**用途：** 作为所有交互物体的基础组件

---

## 🎯 基础效果

### 1. ShowMessageEffect
**文件：** `ShowMessageEffect.cs`  
**功能：** 显示文字消息  
**参数：**
- `Message` - 消息内容
- `Display Duration` - 显示时长
- `Use Debug Log` - 控制台输出

**使用场景：**
- 拾取物品提示
- 剧情文字
- 交互反馈

---

### 2. UnlockInteractableEffect
**文件：** `UnlockInteractableEffect.cs`  
**功能：** 解锁/锁定其他交互物体  
**参数：**
- `Interactables To Unlock` - 目标物体数组
- `Unlock State` - 解锁(true) 或 锁定(false)

**使用场景：**
- 钥匙开门
- 按钮激活机关
- 任务解锁新区域

---

### 3. ChangeAppearanceEffect
**文件：** `ChangeAppearanceEffect.cs`  
**功能：** 改变物体外观  
**参数：**
- `Change Sprite` - 切换精灵图
- `Change Color` - 改变颜色
- `Toggle Visibility` - 显示/隐藏
- `Change Scale` - 改变缩放
- `Use Animation` - 使用动画过渡

**使用场景：**
- 物品被拾取后变灰
- 开关状态切换
- 物体消失/出现效果

---

### 4. PlayAnimationEffect
**文件：** `PlayAnimationEffect.cs`  
**功能：** 播放动画  
**参数：**
- `Target Animator` - Animator组件
- `Animation Trigger` - 触发器名称
- `Use Simple Animation` - 使用内置动画
- `Animation Type` - Bounce/Shake/Pulse

**使用场景：**
- 按钮被按下
- 物品被拾取
- 机关触发反馈

---

### 5. ActivateGameObjectEffect
**文件：** `ActivateGameObjectEffect.cs`  
**功能：** 激活/禁用游戏物体  
**参数：**
- `Target Objects` - 目标物体数组
- `Activate State` - 激活(true) 或 禁用(false)

**使用场景：**
- 显示隐藏物体
- 激活新的谜题元素
- 动态改变场景

---

### 6. SetFlagEffect
**文件：** `SetFlagEffect.cs`  
**功能：** 设置游戏旗标  
**参数：**
- `Flag Key` - 旗标键名
- `Flag Value` - 旗标值

**使用场景：**
- 记录游戏进度
- 解谜状态保存
- 条件判断基础

---

### 7. PlaySoundEffect
**文件：** `PlaySoundEffect.cs`  
**功能：** 播放音效  
**参数：**
- `Audio Clip` - 音频文件
- `Volume` - 音量 (0-1)
- `Pitch` - 音调 (0-3)
- `Create Temporary Source` - 创建临时音源

**使用场景：**
- 交互音效反馈
- 环境音效
- UI音效

---

## 🔗 高级效果

### 8. ChainReactionEffect
**文件：** `ChainReactionEffect.cs`  
**功能：** 触发连锁反应  
**参数：**
- `Target Interactables` - 要触发的物体数组
- `Trigger Sequentially` - 是否顺序触发
- `Sequence Delay` - 顺序延迟时间

**使用场景：**
- 多米诺骨牌效果
- 连锁机关
- 复杂解谜序列

---

### 9. DelayedEffect
**文件：** `DelayedEffect.cs`  
**功能：** 延迟触发 UnityEvent  
**参数：**
- `On Execute` - 执行时的事件
- `On Execute With Actor` - 带参数的事件

**使用场景：**
- 自定义延迟逻辑
- 在Inspector中配置复杂行为
- 快速原型开发

---

## 🛠️ 技术细节

### 基类继承关系

```
IInteractionEffect (接口)
    ↑
BaseInteractionEffect (抽象类)
    ↑
    ├─ ShowMessageEffect
    ├─ UnlockInteractableEffect
    ├─ ChangeAppearanceEffect
    ├─ PlayAnimationEffect
    ├─ ActivateGameObjectEffect
    ├─ SetFlagEffect
    ├─ PlaySoundEffect
    ├─ ChainReactionEffect
    └─ DelayedEffect
```

### 通用参数（所有效果都有）

```csharp
[Header("Effect Settings")]
[SerializeField] protected float executeDelay = 0f;      // 延迟执行
[SerializeField] protected bool executeOnce = false;     // 只执行一次
```

### 通用方法

```csharp
void Execute(GameObject actor)           // 执行效果
bool CanExecute(GameObject actor)        // 检查是否可执行
void ResetEffect()                       // 重置效果状态
```

## 🎨 组合推荐

### 拾取物品组合
```
ShowMessageEffect (提示文字)
+ PlaySoundEffect (拾取音效)
+ ChangeAppearanceEffect (物品变灰或消失)
+ SetFlagEffect (标记已拾取)
```

### 解锁门组合
```
ShowMessageEffect (门打开提示)
+ PlayAnimationEffect (开门动画)
+ PlaySoundEffect (开门音效)
+ UnlockInteractableEffect (解锁下一区域)
```

### 机关按钮组合
```
PlayAnimationEffect (按钮按下)
+ PlaySoundEffect (按钮音效)
+ ShowMessageEffect (机关提示)
+ ActivateGameObjectEffect (显示隐藏物体)
+ ChainReactionEffect (触发其他机关)
```

### 复杂谜题组合
```
PlayAnimationEffect (Delay: 0s)
+ ShowMessageEffect (Delay: 0.5s)
+ SetFlagEffect (Delay: 1s)
+ UnlockInteractableEffect (Delay: 1.5s)
+ ActivateGameObjectEffect (Delay: 2s)
+ ChainReactionEffect (Delay: 2.5s)
```

## 🔍 选择指南

### 我需要... 应该使用...

- **显示文字** → ShowMessageEffect
- **开门/解锁** → UnlockInteractableEffect
- **物品消失** → ChangeAppearanceEffect 或 ActivateGameObjectEffect
- **播放动画** → PlayAnimationEffect
- **播放音效** → PlaySoundEffect
- **记录进度** → SetFlagEffect
- **显示新物体** → ActivateGameObjectEffect
- **触发连锁** → ChainReactionEffect
- **自定义逻辑** → DelayedEffect 或创建新效果

## 💡 扩展建议

如果这些效果还不够用，可以创建以下效果：

1. **ParticleEffect** - 播放粒子效果
2. **CameraShakeEffect** - 摇晃摄像机
3. **DialogueEffect** - 触发对话系统
4. **InventoryEffect** - 添加/移除背包物品
5. **SceneTransitionEffect** - 切换场景
6. **ConditionalEffect** - 条件判断效果
7. **RandomEffect** - 随机选择效果
8. **TimerEffect** - 计时器效果

---

**提示：** 组合使用多个简单效果，比创建一个复杂效果更灵活！
