# 具体交互物品使用指南 🎮

## 📖 系统概述

### 设计理念

**具体脚本，不做通用**：
- ✅ 每个物品一个专门的脚本
- ✅ 代码简单直接，易于理解和修改
- ❌ 不使用复杂的通用系统

### 初始状态
```
场景：
├─ Razor（Razor.cs）
└─ Beard（Beard.cs）

```

### 步骤 1：拾取剃刀

**玩家操作**：
1. 鼠标悬停在剃刀上
2. 显示提示："拾取剃刀"
3. 点击剃刀

**系统反应**：
```
1. held = "razor"
2. 鼠标指针变为剃刀图标 🪒
3. 播放拾取音效
4. 剃刀消失
5. Console: "[Razor] 拾取剃刀"
6. Console: "[Razor] 鼠标指针已更新为剃刀图标"
```

---

### 步骤 2：使用剃刀刮胡子

**玩家操作**：
1. 鼠标悬停在胡子上
2. 显示提示："刮胡子"（因为 held == "razor"）
3. 点击胡子

**系统反应**：
```
1. 检查 held == "razor" ✅
2. 播放刮胡子音效
3. 播放动画："Shave"
4. 黑幕淡入
5. 显示转场文字："第二关"
6. 切换到 Stage_D2
7. 黑幕淡出
8. Console: "[Beard] 刮胡子"
9. Console: "[Beard] 切换到场景: D2"
```

## 📝 添加新物品

### 示例：添加剪刀 + 触角

#### 1. 创建 Scissors.cs

```csharp
using UnityEngine;
using SpookyGame.Core;

namespace SpookyGame.World
{
    [RequireComponent(typeof(Collider2D))]
    public class Scissors : Interactable
    {
        [SerializeField] private Texture2D scissorsCursor;
        [SerializeField] private Vector2 cursorHotspot = new Vector2(16, 16);
        
        public Texture2D ScissorsCursor => scissorsCursor;
        public Vector2 CursorHotspot => cursorHotspot;
        
        public override string CurrentPrompt => "拾取剪刀";
        
        public override bool CanInteract(GameObject actor)
        {
            if (!base.CanInteract(actor)) return false;
            
            string held = FlagService.GetHeldItem();
            if (!string.IsNullOrEmpty(held))
            {
                return false;
            }
            
            return true;
        }
        
        protected override void OnInteract(GameObject actor)
        {
            FlagService.SetHeldItem("scissors");
            
            if (scissorsCursor != null)
            {
                Cursor.SetCursor(scissorsCursor, cursorHotspot, CursorMode.Auto);
            }
            
            gameObject.SetActive(false);
        }
    }
}
```

---

#### 2. 创建 Antenna.cs

```csharp
using UnityEngine;
using SpookyGame.Core;

namespace SpookyGame.World
{
    [RequireComponent(typeof(Collider2D))]
    public class Antenna : Interactable
    {
        [SerializeField] private string targetStageId = "D3";
        [SerializeField] private string intertitle = "第三关";
        [SerializeField] private float fadeDuration = 1f;
        
        public override string CurrentPrompt
        {
            get
            {
                string held = FlagService.GetHeldItem();
                return held == "scissors" ? "剪触角" : "需要剪刀";
            }
        }
        
        public override bool CanInteract(GameObject actor)
        {
            if (!base.CanInteract(actor)) return false;
            
            string held = FlagService.GetHeldItem();
            if (held != "scissors")
            {
                return false;
            }
            
            return true;
        }
        
        protected override void OnInteract(GameObject actor)
        {
            SceneService.FadeToStage(targetStageId, intertitle, fadeDuration);
        }
    }
}
```

## 🎯 设计原则

### 为什么这样设计？

```
✅ 简单直接：
   每个物品一个脚本，看名字就知道是什么

✅ 易于修改：
   修改剃刀行为，只需改 Razor.cs

✅ 易于扩展：
   添加新物品，复制现有脚本即可

❌ 不做通用：
   不需要复杂的配置和枚举
```
