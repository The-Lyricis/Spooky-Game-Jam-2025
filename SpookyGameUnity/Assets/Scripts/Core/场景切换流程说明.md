# 场景切换流程说明

## 🎬 两种切换模式

### 模式 1：带过渡文字的切换（推荐用于叙事）

**流程**：
```
1. 显示过渡文字面板（淡入 0.5秒）
   ↓
2. 在后台切换场景/关卡
   ↓
3. 打字机效果显示文字
   ↓
4. 显示"点击继续"提示
   ↓
5. 等待玩家点击...
   ↓
6. 过渡文字面板淡出（0.5秒）
   ↓
7. 新场景已经显示！✨
```

**使用方法**：
```csharp
// 关卡切换
SceneService.FadeToStage(
    stageId: "D2",
    transitionText: "你推开了门...\n\n里面是一片漆黑。"
);

// 场景切换
SceneService.LoadScene(
    sceneName: "NextScene",
    transitionText: "第一章完成\n\n即将进入第二章..."
);
```

**特点**：
- ✅ 场景在过渡文字显示时就已切换
- ✅ 玩家点击后直接看到新场景
- ✅ 无需黑幕转场
- ✅ 适合有故事叙述的场景切换

---

### 模式 2：传统黑幕转场（用于无叙事切换）

**流程**：
```
1. 黑幕淡入（1秒）
   ↓
2. 显示 Intertitle 标题（2秒，可选）
   ↓
3. 切换场景/关卡
   ↓
4. 黑幕淡出（1秒）
   ↓
5. 新场景显示！
```

**使用方法**：
```csharp
// 不传 transitionText，使用传统黑幕
SceneService.FadeToStage(
    stageId: "D2",
    intertitle: "第二关",
    fadeDuration: 1f
);
```

**特点**：
- ✅ 经典的黑幕转场效果
- ✅ 适合快速切换或无叙事场景
- ✅ 保持向后兼容

---

## 📊 模式对比

| 特性 | 过渡文字模式 | 黑幕模式 |
|------|------------|---------|
| 切换时机 | 显示过渡文字时 | 黑幕完全遮挡后 |
| 玩家体验 | 阅读故事，主动点击 | 被动等待 |
| 适用场景 | 章节切换、剧情转折 | 快速切换、死亡重生 |
| 加载时间 | 隐藏在阅读中 | 明显等待 |

## 🎮 使用建议

### 何时使用过渡文字？

✅ **推荐使用**：
- 章节切换："第一章完成，即将进入第二章"
- 重要剧情点："你发现了真相..."
- 时间跳跃："三天后..."
- 地点转换："你来到了废弃工厂..."
- 游戏结局："游戏通关！感谢游玩。"

❌ **不推荐使用**：
- 死亡重生（太频繁）
- 快速试错场景
- 玩家可能重复看到的切换

### 何时使用黑幕？

✅ **推荐使用**：
- 快速场景切换
- 死亡/失败重试
- 返回主菜单
- 无需叙事的切换

## 💻 代码示例

### 示例 1：章节切换（带文字）

```csharp
public void OnChapter1Complete()
{
    string text = @"
第一章：觉醒 - 完成

你解开了所有谜题，
但这只是序幕...

真正的考验才刚刚开始。
";

    SceneService.FadeToStage("Chapter2_Start", transitionText: text);
}
```

---

### 示例 2：死亡重生（无文字）

```csharp
public void OnPlayerDeath()
{
    // 快速黑幕切换，不使用过渡文字
    SceneService.FadeToStage(
        stageId: "LastCheckpoint",
        intertitle: "重新开始",
        fadeDuration: 0.5f  // 快速转场
    );
}
```

---

### 示例 3：条件选择

```csharp
public void OnSceneTransition(bool useStory)
{
    if (useStory)
    {
        // 使用过渡文字
        SceneService.FadeToStage(
            "NextStage", 
            transitionText: "你做出了选择..."
        );
    }
    else
    {
        // 使用黑幕
        SceneService.FadeToStage(
            "NextStage",
            intertitle: "下一关",
            fadeDuration: 1f
        );
    }
}
```

## 🔧 技术细节

### 关卡切换（FadeToStage）

**有过渡文字时**：
```
显示过渡文字 → 等0.5秒 → 切换关卡 → 等玩家点击 → 完成
```

**无过渡文字时**：
```
黑幕淡入 → 等1秒 → 显示标题 → 等2秒 → 切换关卡 → 黑幕淡出 → 完成
```

### 场景切换（LoadScene）

**有过渡文字时**：
```
显示过渡文字 → 等0.5秒 → 异步加载场景 → 等玩家点击 → 激活场景 → 完成
```

**无过渡文字时**：
```
直接异步加载场景 → 完成
```

## ⚙️ 可配置参数

### 过渡文字显示时间

修改 `TransitionTextUI.cs` 中的：
- `fadeInDuration` - 过渡面板淡入时长（默认 0.5秒）
- `typingSpeed` - 打字速度（默认 0.05秒/字）

### 场景切换等待时间

修改 `SceneService.cs` 中的：
```csharp
yield return new WaitForSeconds(0.5f); // 等待过渡UI淡入
```

可以根据你的过渡UI淡入时长调整。

## 🎉 优势总结

### 过渡文字模式的优势

1. **隐藏加载时间** - 玩家在阅读时，场景已经切换完成
2. **增强叙事感** - 文字承上启下，故事连贯
3. **玩家主导** - 玩家控制节奏，点击继续
4. **提升体验** - 比单纯的黑幕更有趣

### 实现优势

1. **向后兼容** - 不传 `transitionText` 时保持原有功能
2. **灵活选择** - 根据场景需求选择模式
3. **性能优化** - 异步加载，不卡顿
4. **易于使用** - 只需一个参数即可启用

---

## 📝 注意事项

1. **过渡文字长度** - 建议 2-5 行，不要太长
2. **加载时间** - 如果场景很大，可能还是会有加载延迟
3. **UI 层级** - 确保 TransitionTextCanvas Sort Order 正确
4. **事件订阅** - 确保 TransitionTextUI 正确订阅了事件
