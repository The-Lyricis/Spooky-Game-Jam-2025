# 场景切换过渡文字系统使用指南

## 📁 文件说明

- **TransitionTextUI.cs** - 过渡文字 UI 控制器
- **SceneService.cs** - 已添加过渡文字支持

---

## 🎮 功能特性

### 核心功能
- ✅ **打字机效果** - 文字逐字显示
- ✅ **点击跳过** - 可跳过打字机动画
- ✅ **等待点击** - 文字显示完后等待玩家点击
- ✅ **闪烁提示** - "点击继续..." 提示闪烁
- ✅ **淡入淡出** - 平滑的显示和隐藏动画
- ✅ **事件驱动** - 通过 EventBus 控制

## ✅ 快速设置（5分钟）

### 步骤 1：创建 UI

#### 1.1 创建 Canvas

```
Hierarchy > 右键 > UI > Canvas
重命名为 "TransitionTextCanvas"
设置 Sort Order = 99 (在 FadeScreen 之下，确保黑幕在最上层)
```

#### 1.2 创建过渡面板

```
右键 TransitionTextCanvas > UI > Panel
重命名为 "TransitionPanel"
```

**配置面板**：
- Image 颜色：RGBA (0, 0, 0, 200) - 半透明黑色背景
- Anchor：Stretch 全屏
- Raycast Target：✓ 勾选

#### 1.3 创建文字显示

```
右键 TransitionPanel > UI > Text
重命名为 "TransitionText"
```

**配置文字**：
- 字体大小：24-32
- 颜色：白色
- 对齐：水平居中、垂直居中
- Width：800-1000
- Height：300-400
- Anchor：Center
- 最佳行距：1.2

#### 1.4 创建点击提示

```
右键 TransitionPanel > UI > Text
重命名为 "ClickPromptText"
```

**配置提示**：
- 文字：留空（运行时设置）
- 字体大小：18-20
- 颜色：白色
- 对齐：水平居中、垂直居中
- Anchor：Bottom Center
- Pos Y：50（距离底部 50）

#### 1.5 挂载脚本

选中 `TransitionTextCanvas`，添加 `TransitionTextUI.cs` 脚本

**配置脚本**：
- **Transition Panel**：拖入 TransitionPanel
- **Transition Text**：拖入 TransitionText
- **Click Prompt Text**：拖入 ClickPromptText
- **Typing Speed**：0.05（每个字 0.05 秒）
- **Skip On Click**：✓ 勾选
- **Click Prompt Message**："点击继续..."

---

### 步骤 2：UI 层级结构验证

最终结构应该是：

```
TransitionTextCanvas
├─ Canvas (Sort Order: 99)
├─ TransitionTextUI.cs
└─ TransitionPanel (半透明黑色背景)
    ├─ TransitionText (主要文字)
    └─ ClickPromptText (点击提示)
```

## 🎯 使用方法

### 方法 1：在场景切换时使用

```csharp
using SpookyGame.Core;

// 不带过渡文字（原有功能）
SceneService.LoadScene("Scene_2");

// 带过渡文字（新功能）
SceneService.LoadScene("Scene_2", null, "第一章完成\n\n即将进入第二章...");
```

**完整示例**：
```csharp
// 场景切换，显示过渡文字
SceneService.LoadScene(
    sceneName: "NextScene",
    onComplete: () => Debug.Log("场景加载完成"),
    transitionText: "经过一番调查，你发现了惊人的真相...\n\n但更大的秘密还在后面等着你。"
);
```

---

### 方法 2：在关卡切换时使用

```csharp
using SpookyGame.Core;

// 不带过渡文字（原有功能）
SceneService.FadeToStage("D2");

// 带过渡文字（新功能）
SceneService.FadeToStage(
    stageId: "D2",
    intertitle: "第二关",
    fadeDuration: 1f,
    transitionText: "你推开了沉重的大门...\n\n里面是一片漆黑。"
);
```

**执行顺序**：
1. 显示过渡文字面板（淡入）
2. 打字机效果显示文字
3. 显示"点击继续"提示
4. 等待玩家点击
5. 过渡文字面板淡出
6. 黑幕淡入
7. 显示 Intertitle（如果有）
8. 切换关卡
9. 黑幕淡出

### 方法 3：直接使用事件系统

```csharp

    }

```

## ⚙️ 配置说明

### TransitionTextUI 参数

#### Typewriter Settings（打字机设置）
- **Typing Speed**：每个字显示间隔（秒）
  - 推荐值：0.03-0.08
  - 0.05 = 正常速度
  - 0.03 = 快速
  - 0.08 = 慢速
- **Skip On Click**：是否允许点击跳过打字机效果
  - 推荐：✓ 勾选

#### Animation Settings（动画设置）
- **Fade In Duration**：淡入时长（秒）
  - 推荐值：0.3-0.8
- **Fade Out Duration**：淡出时长（秒）
  - 推荐值：0.3-0.8

#### Prompt Settings（提示设置）
- **Click Prompt Message**：点击提示文字
  - 推荐："点击继续..." 或 "Click to continue..."
- **Prompt Blink Speed**：提示闪烁速度（秒）
  - 推荐值：0.8-1.5

## 🐛 常见问题

### Q: 文字显示太快/太慢？

A: 调整 `Typing Speed` 参数：
- 减小值 = 更快
- 增大值 = 更慢
- 推荐范围：0.03-0.08

### Q: 点击无法跳过打字机？

A: 检查：
1. `Skip On Click` 是否勾选
2. TransitionPanel 的 `Raycast Target` 是否勾选
3. Canvas 是否有 `Graphic Raycaster` 组件

### Q: "点击继续"提示不显示？

A: 检查：
1. `Click Prompt Text` 是否已赋值
2. ClickPromptText GameObject 是否存在
3. `Click Prompt Message` 字段是否为空

### Q: 过渡文字不显示？

A: 检查：
1. 场景中是否有 TransitionTextUI 组件
2. 是否调用了带 `transitionText` 参数的方法
3. Console 是否有错误日志
4. EventBus 是否已初始化

### Q: 文字显示不完整？

A: 增大 TransitionText 的宽度和高度，或减小字体大小。

过渡文字系统会在黑幕转场之前显示：

```
过渡文字（Sort Order: 99）
    ↓ 玩家点击

```

确保 Canvas Sort Order 设置正确：
- FadeScreen: 100（最上层）
- TransitionTextCanvas: 99（中间层）
- 其他 UI: < 99（下层）

## 💡 高级技巧

### 技巧 1：多段文字

使用协程实现多段文字连续播放：

```csharp
IEnumerator ShowMultipleTexts()
{
    string[] texts = {
        "第一段话...",
        "第二段话...",
        "第三段话..."
    };
    
    foreach (string text in texts)
    {
        bool textComplete = false;
        EventBus.Publish(new TransitionTextEvent(text, true, () => {
            textComplete = true;
        }));
        
        yield return new WaitUntil(() => textComplete);
        yield return new WaitForSeconds(0.5f); // 间隔
    }
    
    // 所有文字显示完成
    SceneService.LoadScene("NextScene");
}
```

### 技巧 2：动态文字内容

根据游戏状态生成文字：

```csharp
string GetTransitionText()
{
    int completedClues = FlagService.GetFlag("clues_found", 0);
    
    if (completedClues >= 5)
    {
        return "你已经找到了所有线索！\n\n真相即将揭晓...";
    }
    else
    {
        return $"你找到了 {completedClues} 个线索。\n\n继续探索吧。";
    }
}

SceneService.LoadScene("NextScene", null, GetTransitionText());
```
