# 过渡文字系统快速参考 ⚡

## 🚀 最快 3 步设置

### 1️⃣ 创建 UI (2分钟)

```
TransitionTextCanvas (Canvas, Sort Order: 99)
└─ TransitionPanel (Panel, 半透明黑色)
    ├─ TransitionText (Text, 居中, 800x400)
    └─ ClickPromptText (Text, 底部居中)
```

挂载 `TransitionTextUI.cs` 到 Canvas，拖入 3 个引用。

---

### 2️⃣ 使用代码 (1分钟)

```csharp
using SpookyGame.Core;

// 场景切换 + 过渡文字
SceneService.LoadScene("NextScene", null, "过渡文字内容...");

// 关卡切换 + 过渡文字
SceneService.FadeToStage("D2", "第二关", 1f, "过渡文字内容...");
```

---

### 3️⃣ 测试 (30秒)

运行游戏 → 触发切换 → 看到文字逐字显示 → 点击继续 → 完成！

## ⚙️ 推荐配置

### TransitionTextUI 参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| Typing Speed | 0.05 | 打字速度 |
| Skip On Click | ✓ | 允许跳过 |
| Fade In Duration | 0.5 | 淡入时长 |
| Fade Out Duration | 0.5 | 淡出时长 |
| Click Prompt Message | "点击继续..." | 提示文字 |
| Prompt Blink Speed | 1.0 | 闪烁速度 |

### TransitionText 设置

| 属性 | 值 |
|------|-----|
| 字体大小 | 24-32 |
| 颜色 | 白色 |
| 对齐 | 居中 |
| 宽度 | 800-1000 |
| 高度 | 300-400 |
| 行距 | 1.2 |

## 🐛 快速排错

| 问题 | 解决方案 |
|------|----------|
| 文字不显示 | 检查场景中是否有 TransitionTextUI 组件 |
| 无法点击 | 检查 TransitionPanel 的 Raycast Target |
| 文字太快 | 增大 Typing Speed 值（如 0.08） |
| 文字太慢 | 减小 Typing Speed 值（如 0.03） |
| 提示不闪烁 | 检查 ClickPromptText 是否已赋值 |

## 💡 实用技巧

### 换行技巧

```csharp
"第一行\n第二行"           // 单换行
"第一段\n\n第二段"         // 空行
@"
多行
文字
内容
"                          // 使用 @ 字符串
```

### 动态内容

```csharp
int clues = FlagService.GetFlag("clues_found", 0);
string text = $"你找到了 {clues} 个线索。\n\n继续探索吧。";
SceneService.LoadScene("NextScene", null, text);
```

### 条件文字

```csharp
string text = FlagService.GetFlag("good_ending") 
    ? "你做出了正确的选择。" 
    : "你的选择导致了悲剧...";
    
SceneService.LoadScene("Ending", null, text);
```

## 📊 执行流程

```
1. 显示过渡文字面板（淡入）
   ↓
2. 打字机效果（可跳过）
   ↓
3. 显示"点击继续"（闪烁）
   ↓
4. 等待玩家点击
   ↓
5. 面板淡出
   ↓
6. 场景/关卡切换
```

Sort Order: 1   - 提示 UI
