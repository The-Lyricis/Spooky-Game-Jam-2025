# 配置快速修复指南 🔧

## ❌ 错误信息
```
Scene 'GameScene' couldn't be loaded because it has not been added 
to the build settings or the AssetBundle has not been loaded.
```

## 🎯 问题原因
**GameConfig 中配置的场景名与实际场景文件名不一致！**

---

## ✅ 解决方案（选择其一）

### 方案 1：修改 GameConfig 配置（推荐⭐）

#### 步骤：
1. 在 Unity Project 窗口找到 `GameConfig.asset`
2. 在 Inspector 中找到 `Game Scene Name` 字段
3. 将值改为：`Scene_0`（你的实际场景名）
4. 保存（Ctrl+S）

#### 配置示例：
```
Scene Names
├─ Main Menu Scene Name: MainMenu    ← 正确
└─ Game Scene Name: Scene_0          ← 改为这个！
```

---

### 方案 2：重命名场景文件

#### 步骤：
1. 在 Project 窗口找到 `Assets/Scenes/Scene_0.unity`
2. 右键 → Rename
3. 改为：`GameScene`
4. 打开 `File > Build Settings`
5. 确认场景列表中的名称已更新

---

## 📝 完整配置检查清单

### 1️⃣ 场景文件检查
在 `Assets/Scenes/` 中，你应该有：
- ✅ `MainMenu.unity` - 主菜单场景
- ✅ `Scene_0.unity` - 游戏场景（或改名为 `GameScene.unity`）

### 2️⃣ GameConfig 配置检查
打开 `GameConfig.asset`，检查：

```
Scene Names
├─ Main Menu Scene Name: MainMenu    ← 必须与文件名完全一致
└─ Game Scene Name: Scene_0          ← 必须与文件名完全一致（不含 .unity）

Stage Configuration
├─ First Stage Id: D1
└─ Stages (Size: 1+)
    └─ [0]
        ├─ Stage Id: D1              ← 必须与场景中的 Stage_D1 对应
        ├─ Display Name: DAY 1
        └─ Intertitle: DAY 1 · 第一天
```

### 3️⃣ Build Settings 检查
打开 `File > Build Settings`，确认：

```
Scenes In Build
├─ [0] Assets/Scenes/MainMenu.unity    ✓ (勾选)
└─ [1] Assets/Scenes/Scene_0.unity     ✓ (勾选)
     （或 GameScene.unity）
```

⚠️ **如果场景不在列表中**：
1. 将场景文件从 Project 窗口拖入 Build Settings
2. 确保场景左侧的复选框被勾选

### 4️⃣ 场景层级结构检查

#### Scene_0.unity（游戏场景）必须有：
```
Scene_0
├─ Shared
│   └─ Bootstrap                      ← 挂载 Bootstrap.cs
│       └─ Game Config → 引用 GameConfig.asset
└─ Stage_D1                           ← 名称必须与 GameConfig 中的 stageId 对应
    └─ （初始状态：禁用）
```

⚠️ **关键点**：
- `Stage_D1` 的名称格式必须是 `Stage_[ID]`
- `[ID]` 必须与 `GameConfig.stages[0].stageId` 完全一致
- 初始状态必须是禁用（取消勾选左侧复选框）

## 🔍 常见配置错误

### 错误 1：场景名拼写错误
```
❌ GameConfig: Game Scene Name = "GameScene"
❌ 实际文件名: Scene_0.unity
✅ 解决方法: 改为 Scene_0 或重命名文件
```

### 错误 2：场景未添加到 Build Settings
```
❌ Build Settings 列表为空或缺少场景
✅ 解决方法: 将场景拖入 Build Settings
```

### 错误 3：场景名大小写错误
```
❌ GameConfig: "scene_0"（小写）
❌ 实际文件名: Scene_0（大写 S）
✅ 解决方法: 确保大小写完全一致
```

### 错误 4：Stage ID 不匹配
```
❌ GameConfig: First Stage Id = "D1"
❌ 场景中的节点名: Stage_Day1
✅ 解决方法: 统一为 Stage_D1
```

3. 点击"开始游戏"按钮

### 2. 观察 Console 输出
**正确的日志应该是**：
```

[MainMenu] Starting new game
[FlagService] Cleared all flags
[SceneService] Loading scene: Scene_0
[SceneService] Scene loaded successfully: Scene_0
[SceneService] Fading to stage: D1

[SceneService] Activated stage: D1

**如果看到错误**：
```
❌ Scene 'XXX' couldn't be loaded
   → 场景名配置错误或未添加到 Build Settings

❌ Stage D1 not found!
   → 场景中没有 Stage_D1 GameObject 或名称不匹配
```

## 📊 配置对照表

| 配置项 | 配置位置 | 正确值示例 | 常见错误 |
|--------|---------|-----------|---------|
| **主菜单场景名** | GameConfig.mainMenuSceneName | `MainMenu` | `mainmenu`（大小写错误） |
| **游戏场景名** | GameConfig.gameSceneName | `Scene_0` | `GameScene`（文件名不存在） |
| **首关ID** | GameConfig.firstStageId | `D1` | `Day1`（与 Stage 名称不匹配） |
| **Stage GameObject** | 场景层级 | `Stage_D1` | `Stage_Day1`（格式错误） |
| **Build Settings** | File > Build Settings | 已添加且勾选 | 未添加或未勾选 |

├─ Stage_D1  → Day 1

├─ MainMenu.unity
└─ Scene_0.unity           ← 保持不变

GameConfig 配置：
├─ Main Menu Scene Name: MainMenu
├─ Game Scene Name: Scene_0    ← 改为这个

```

## 🆘 如果还是不行

### 调试步骤：

1. **确认场景文件存在**
   ```
   Assets/Scenes/Scene_0.unity  ← 是否存在？
   ```

2. **确认 GameConfig 已保存**
   - 修改后按 Ctrl+S
   - 查看 Inspector 中的值是否已更新

3. **确认 Bootstrap 引用了 GameConfig**
   - 选中 MainMenu 场景的 Bootstrap GameObject
   - 检查 Inspector 中的 Game Config 字段是否已赋值

4. **查看完整错误信息**
   - 在 Console 中双击错误
   - 查看完整的堆栈跟踪
   - 确认是哪个场景名出错了

5. **重启 Unity**
   - 有时候配置修改需要重启 Unity 才能生效
