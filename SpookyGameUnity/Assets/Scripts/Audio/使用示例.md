# 背景音乐系统集成示例

## 🎵 集成到现有游戏

### 步骤 1：在 Bootstrap 场景中添加音乐管理器

1. 打开 `MainMenu` 或 `Scene_0` 场景
2. 在 Hierarchy 中找到 `Shared` 节点（或创建一个）
3. 右键 `Shared` > `Create Empty`
4. 重命名为 `BackgroundMusicManager`
5. 挂载 `BackgroundMusicManager.cs` 脚本

### 步骤 2：配置管理器

在 Inspector 中设置：
```
Default Music: 拖入你的背景音乐 AudioClip
Play On Awake: ✓ 勾选
Loop: ✓ 勾选
Volume: 0.5
Fade In Duration: 2
Fade Out Duration: 2
```

### 步骤 3：准备音乐资源

将你的音乐文件（.mp3, .wav, .ogg）拖入 `Assets/Audio/` 文件夹。

## 🔧 与 Bootstrap 集成

如果你想在 `Bootstrap.cs` 中初始化音乐，可以这样修改：

```csharp
// 在 Bootstrap.cs 的 InitializeServices() 方法中添加：

private void InitializeServices()
{
    // 初始化事件总线
    EventBus.Initialize();
    
    // 初始化场景服务
    SceneService.Initialize(this);
    
    // 初始化旗标服务
    FlagService.Initialize();
    
    // 初始化输入服务
    InputService.Initialize();
    
    // 【新增】初始化音乐系统
    InitializeAudio();
    
    Debug.Log("[Bootstrap] All services initialized");
}

// 添加新方法：
private void InitializeAudio()
{
    // 确保音乐管理器已创建
    var musicManager = BackgroundMusicManager.Instance;
    
    // 可选：从 GameConfig 读取音乐设置
    if (gameConfig != null && gameConfig.defaultBackgroundMusic != null)
    {
        musicManager.PlayMusic(gameConfig.defaultBackgroundMusic);
    }
    
    Debug.Log("[Bootstrap] Audio initialized");
}
```

## 🎪 场景音乐切换示例

### 示例 1：主菜单使用独立音乐

在 `MainMenu.cs` 的 `Start()` 方法中：

```csharp
private void Start()
{
    // 播放主菜单音乐
    if (menuMusic != null)
    {
        BackgroundMusicManager.Instance.PlayMusic(menuMusic, 2f);
    }
}
```

### 示例 2：每个关卡使用不同音乐

在每个 `Stage` 节点下添加 `MusicPlayer` 组件：

```
Stage_D1
├─ MusicPlayer (挂载 MusicPlayer.cs)
│   ├─ Music Clip: Stage1Music
│   ├─ Play On Enable: ✓
│   └─ Fade In Duration: 2
```

当 `Stage_D1` 激活时，会自动播放对应的音乐。

## 🎬 在交互效果中使用

### 示例 1：点击物体播放音乐

创建一个新的交互效果 `PlayMusicEffect.cs`：

```csharp
using UnityEngine;
using SpookyGame.Audio;
using SpookyGame.World.InteractionEffects;

public class PlayMusicEffect : BaseInteractionEffect
{
    [SerializeField] private AudioClip musicClip;
    [SerializeField] private float fadeDuration = 2f;
    
    protected override void ExecuteImmediate(GameObject actor)
    {
        if (musicClip != null)
        {
            BackgroundMusicManager.Instance.PlayMusic(musicClip, fadeDuration);
            Debug.Log($"[PlayMusicEffect] Playing: {musicClip.name}");
        }
    }
}
```

挂载到可交互物体上，点击后播放特定音乐。

## 💡 使用技巧

### 1. 音乐循环播放
确保 `Loop` 选项勾选，音乐会无限循环。

### 2. 淡入淡出效果
使用淡入淡出可以让音乐切换更自然，推荐：
- 淡入：2-3秒
- 淡出：1-2秒

### 3. 音量设置
- 背景音乐：0.3 - 0.5（不要太大声）
- 音效：0.7 - 1.0（需要突出）

### 4. 跨场景音乐
由于使用了 `DontDestroyOnLoad`，音乐管理器会在场景切换时保留。如果想在特定场景使用不同音乐，使用 `MusicPlayer` 组件。

## 🐛 常见问题

### Q: 音乐没有播放？
A: 检查：
1. AudioClip 是否已赋值
2. Play On Awake 是否勾选
3. Volume 是否大于 0
4. 音频导入设置是否正确

### Q: 场景切换时音乐停止了？
A: 确保 BackgroundMusicManager 在第一个场景中创建，它会自动持久化。

### Q: 音乐切换不平滑？
A: 增加 Fade In/Out Duration 的值（推荐 2-3秒）。

### Q: 如何在代码中动态加载音乐？
A: 使用 Resources 或 Addressables：
```csharp
AudioClip clip = Resources.Load<AudioClip>("Audio/MyMusic");
BackgroundMusicManager.Instance.PlayMusic(clip);
```
