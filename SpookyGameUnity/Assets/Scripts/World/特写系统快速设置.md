# 特写系统快速设置清单 ⚡

按照这个清单快速设置物品特写查看功能！

---

## ✅ 步骤 1：创建 UI（5分钟）

### 1.1 创建 Canvas

- [ ] `Hierarchy > 右键 > UI > Canvas`
- [ ] 重命名为 `CloseupViewCanvas`
- [ ] 设置 `Sort Order = 100`

### 1.2 创建背景面板

- [ ] 右键 `CloseupViewCanvas > UI > Panel`
- [ ] 重命名为 `CloseupPanel`
- [ ] 设置 Image 颜色：RGBA (0, 0, 0, 150)
- [ ] 设置 Anchor：**Stretch** 全屏
- [ ] 确保 `Raycast Target` ✓ 勾选

### 1.3 创建特写图片

- [ ] 右键 `CloseupPanel > UI > Image`
- [ ] 重命名为 `CloseupImage`
- [ ] 设置宽度：800，高度：600
- [ ] 勾选 `Preserve Aspect` ✓
- [ ] 确保 `Raycast Target` ✓ 勾选
- [ ] 设置 Anchor：**Center**

### 1.4 挂载脚本

- [ ] 选中 `CloseupViewCanvas`
- [ ] 添加 `CloseupViewUI.cs` 脚本
- [ ] 拖入 `CloseupPanel` 到 **Closeup Panel** 字段
- [ ] 拖入 `CloseupImage` 到 **Closeup Image** 字段

### 1.5 验证设置

最终结构应该是：
```
CloseupViewCanvas
├─ Canvas (Sort Order: 100)
├─ CloseupViewUI.cs
└─ CloseupPanel (RGBA: 0,0,0,150)
    └─ CloseupImage (800x600, Preserve Aspect ✓)
```

---

## ✅ 步骤 2：创建可查看的物体（3分钟）

### 2.1 创建或选择物体

- [ ] 在 Hierarchy 中选择要变成可查看的物体
- [ ] 或创建新物体：`右键 > 2D Object > Sprite`

### 2.2 设置 Sprite 和 Collider

- [ ] 设置 `Sprite Renderer` 的 Sprite（物体外观）
- [ ] 添加 `Collider2D`（如 BoxCollider2D）
- [ ] 确保 Collider 大小合适

### 2.3 挂载脚本

- [ ] 添加 `InspectableObject.cs` 脚本

### 2.4 配置脚本

**Interaction Settings**：
- [ ] `Interaction Prompt = "查看"`
- [ ] `Can Interact Multiple Times` ✓

**Closeup Settings**：
- [ ] 拖入特写图片到 `Closeup Sprite`
  - 或勾选 `Use Object Sprite` 使用物体自身图片
- [ ] 确保 `Auto Find UI` ✓ 勾选

---

## ✅ 步骤 3：测试（1分钟）

### 3.1 运行场景

- [ ] 点击 Unity 的 **Play** 按钮

### 3.2 测试功能

- [ ] **点击物体** - 应该显示特写面板
- [ ] **鼠标滚轮** - 应该能缩放图片
- [ ] **鼠标左键拖动** - 应该能移动图片
- [ ] **点击外部黑色区域** - 应该关闭特写

### 3.3 检查 Console

应该看到以下日志：
```
[InspectableObject] YourObject: Showing closeup of YourSprite
[CloseupViewUI] Showing closeup: YourSprite
```

## 🐛 问题排查

### 问题：点击物体没反应

检查：
- [ ] 物体是否有 `Collider2D` 组件
- [ ] Collider 是否启用（enabled = true）
- [ ] 场景中是否有 `Interactor` 组件（负责检测点击）
- [ ] Console 是否有错误日志

### 问题：特写面板不显示

检查：
- [ ] `CloseupViewUI` 是否正确挂载到 Canvas 上
- [ ] `Closeup Sprite` 是否已设置
- [ ] Canvas 的 `Canvas` 组件是否启用
- [ ] Console 是否有 "CloseupViewUI not found" 错误

### 问题：无法拖动图片

检查：
- [ ] `CloseupImage` 的 `Raycast Target` 是否勾选
- [ ] Canvas 是否有 `Graphic Raycaster` 组件（自动添加）
- [ ] `Enable Drag` 是否勾选

### 问题：点击外部无法关闭

检查：
- [ ] `CloseupPanel` 的 `Raycast Target` 是否勾选
- [ ] `CloseupPanel` 的 Image 颜色 Alpha 是否大于 0

## 📋 配置参考值

### CloseupViewUI 推荐设置

```
Zoom Settings:
├─ Min Zoom: 0.5
├─ Max Zoom: 3.0
└─ Zoom Speed: 0.1

Drag Settings:
├─ Enable Drag: ✓
└─ Drag Speed: 1.0

Animation Settings:
├─ Fade In Duration: 0.2
└─ Fade Out Duration: 0.2
```

### InspectableObject 推荐设置

```
Interaction Settings:
├─ Interaction Prompt: "查看"
├─ Can Interact Multiple Times: ✓
└─ Interaction Cooldown: 0.5

Closeup Settings:
├─ Closeup Sprite: [拖入图片]
└─ Use Object Sprite: □ (除非想用物体本身的图片)

UI Reference:
├─ Closeup UI: [自动查找]
└─ Auto Find UI: ✓
```

## 🎨 美术资源准备

### 需要准备的图片

1. **场景中的小图标** (128x128 或 256x256)
   - 用于 SpriteRenderer，显示在场景中
   - 例如：diary_icon.png, photo_icon.png

2. **特写大图** (1024x1024 或更大)
   - 用于 CloseupSprite，显示在特写面板中
   - 例如：diary_closeup.png, photo_closeup.png

### 图片导入设置

```
Texture Import Settings:
├─ Texture Type: Sprite (2D and UI)
├─ Sprite Mode: Single
├─ Pixels Per Unit: 100
├─ Max Size: 2048 (特写图) 或 512 (图标)
└─ Compression: High Quality
```
