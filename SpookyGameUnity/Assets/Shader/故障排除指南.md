# Who's Lila Shader - 故障排除指南

## 🚨 常见问题及解决方案

---

## ❌ 问题1：只有像素化，其他效果不生效

### 症状：
- ✅ 像素化效果正常
- ❌ 颜色量化无效
- ❌ 对比度调整无效
- ❌ 扫描线不显示
- ❌ 调整参数没有任何变化

### 根本原因：
**材质使用了错误的Shader！**

材质可能指向Unity内置的Sprite Shader，而不是我们的自定义Shader。

### 解决方法A：在Unity Inspector中修改（推荐）

1. **选中材质**
   ```
   Project窗口 → Assets/Material/WhosLilaMaterial
   ```

2. **检查Shader设置**
   ```
   Inspector → 最顶部的 Shader 下拉菜单
   当前显示：Sprites/Default ← 这是错误的！
   ```

3. **选择正确的Shader**
   ```
   点击 Shader 下拉菜单
   搜索：WhosLila
   选择：Custom/WhosLilaPixelate
   ```

4. **验证修改**
   ```
   应该显示：Shader: Custom/WhosLilaPixelate
   下方应该出现所有自定义参数
   ```

### 解决方法B：重新创建材质

如果上述方法不行：

1. **删除旧材质**
   ```
   选中 WhosLilaMaterial
   Delete键删除
   ```

2. **创建新材质**
   ```
   Assets/Material 右键
   Create → Material
   命名：WhosLilaMaterial
   ```

3. **分配Shader**
   ```
   Inspector → Shader 下拉菜单
   选择：Custom/WhosLilaPixelate
   ```

4. **重新配置Renderer Feature**
   ```
   Renderer2D.asset → WhosLilaRenderFeature
   Effect Material: 拖入新材质
   ```

### 验证是否修复成功：

播放场景后应该看到：
- ✅ 像素化效果
- ✅ 颜色被限制（6-8种颜色）
- ✅ 高对比度效果
- ✅ 抖动过渡
- ✅ CRT扫描线
- ✅ 调整参数有明显变化

## ❌ 问题2：完全看不到任何效果

### 检查清单：

#### 1. 检查Renderer Feature配置
```
Assets/Settings/Renderer2D.asset
Inspector → Renderer Features
[ ] WhosLilaRenderFeature 是否存在？
[ ] Active 是否勾选？ ☑
[ ] Effect Material 是否已分配？
```

#### 2. 检查材质Shader
```
Assets/Material/WhosLilaMaterial
Inspector → Shader
应该显示：Custom/WhosLilaPixelate
不应该是：Sprites/Default
```

#### 3. 检查摄像机设置
```
Main Camera → Camera组件 → Rendering
[ ] Renderer: Renderer2D
[ ] Post Processing: ☑
```

#### 4. 检查Console错误
```
Window → General → Console
是否有红色错误？
是否有警告信息？
```

## ❌ 问题3：效果太弱或不明显

### 原因：
参数设置过于保守

### 解决方法：
使用**极端参数**测试：

```
在 Renderer2D.asset 的 WhosLilaRenderFeature 中设置：

Pixel Size: 200          ← 非常大的像素块
Color Count: 4           ← 只有4种颜色
Contrast: 3.0            ← 极高对比度
Brightness: -0.3         ← 很暗
Saturation: 0.0          ← 完全黑白
Dither Strength: 1.0     ← 最强抖动
Scanline Intensity: 1.0  ← 最强扫描线
Vignette: 1.0           ← 最强暗角
```

如果这样还看不到效果，说明Shader根本没有生效。

---

## ❌ 问题4：调整参数没有反应

### 可能原因1：在错误的地方调整参数

**错误位置：**
- ❌ 在材质上直接调整参数（无效！）
- ❌ 在摄像机组件上调整（没有这些参数）

**正确位置：**
- ✅ 在 `Renderer2D.asset` 的 `WhosLilaRenderFeature` 中调整

### 可能原因2：Play模式下修改未生效

**解决方法：**
1. 停止Play模式
2. 在 Renderer2D.asset 中调整参数
3. 重新播放场景

### 可能原因3：参数更新延迟

**解决方法：**
调整参数后：
1. 保存场景（Ctrl+S）
2. 停止Play
3. 重新播放

---

## ❌ 问题5：场景变黑/变奇怪

### 原因：
Shader编译错误或参数设置极端

### 解决方法：

#### 步骤1：检查Shader错误
```
选中 PixelateShader.shader
查看 Inspector 底部
是否有错误信息？
```

#### 步骤2：重置参数为默认值
```
在 Renderer2D.asset 的 WhosLilaRenderFeature：

Pixel Size: 120
Color Count: 8
Contrast: 1.8
Brightness: 0
Saturation: 0.7
Dither Strength: 0.5
Dither Scale: 4
Scanline Intensity: 0.2
Scanline Count: 240
Noise Amount: 0.05
Vignette: 0.3
Grain Size: 2
Grain Amount: 0.08
```

---

## ❌ 问题6：性能问题/帧率低

### 优化方案：

#### 1. 降低扫描线计算
```
Scanline Count: 120（从240降低）
```

#### 2. 减少动态效果
```
Noise Amount: 0（关闭噪点）
Grain Amount: 0（关闭颗粒）
```

#### 3. 降低游戏分辨率
```
Edit → Project Settings → Player
Resolution → Default Screen Width/Height
设置为更小的值
```

#### 4. 简化参数
```
只保留核心效果：
- Pixel Size
- Color Count
- Contrast
其他效果设为0或最小值
```

## 🔍 调试方法

### 方法1：使用极端参数测试

设置一个参数为极端值，观察是否有变化：

```
测试像素化：Pixel Size = 500（巨大）
测试颜色量化：Color Count = 2（只有黑白）
测试对比度：Contrast = 3.0（极高）
测试扫描线：Scanline Intensity = 1.0（全黑）
```

哪个有效果，说明哪个功能正常。

### 方法2：添加调试日志

在 `WhosLilaRenderPass.cs` 的 `Execute` 方法开头添加：

```csharp
public override void Execute(ScriptableRenderContext context, ref RenderingData renderingData)
{
    Debug.Log($"Who's Lila Effect Running - Material: {effectMaterial?.name}");
    
    // ... 其余代码
}
```

如果Console中持续输出这条信息，说明渲染通道在工作。

### 方法3：使用Frame Debugger

```
Window → Analysis → Frame Debugger
点击 Enable
查找 "WhosLilaEffect" 渲染步骤
点击查看该步骤的输出
```

## ✅ 完整验证清单

复制此清单，逐项检查：

### Shader检查
- [ ] PixelateShader.shader 存在于 Assets/Shader/
- [ ] Shader 无编译错误（无红色波浪线）
- [ ] Shader 名称为 "Custom/WhosLilaPixelate"

### 材质检查
- [ ] WhosLilaMaterial 存在于 Assets/Material/
- [ ] 材质的 Shader 是 **Custom/WhosLilaPixelate**（不是 Sprites/Default）
- [ ] 材质显示所有自定义参数

### Renderer Feature检查
- [ ] Renderer2D.asset 中已添加 WhosLilaRenderFeature
- [ ] Active 已勾选 ☑
- [ ] Effect Material 已分配 WhosLilaMaterial
- [ ] 参数已调整（不使用全部默认值）

### 摄像机检查
- [ ] Main Camera 的 Renderer 是 Renderer2D
- [ ] Post Processing 已勾选 ☑

### 脚本检查
- [ ] WhosLilaRenderPass.cs 无编译错误
- [ ] WhosLilaRenderFeature.cs 无编译错误
- [ ] Console 无红色错误

### 效果检查
- [ ] 播放场景看到像素化
- [ ] 看到颜色限制效果
- [ ] 调整参数有明显变化
- [ ] 看到扫描线（或增大Scanline Intensity到0.5测试）
