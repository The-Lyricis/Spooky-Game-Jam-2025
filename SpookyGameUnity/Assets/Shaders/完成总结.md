## 📊 技术实现细节

### 顶点抖动公式
```
ΔX = Strength_X × sin(Frequency_X × Time × Speed + Seed)
ΔY = Strength_Y × cos(Frequency_Y × Time × Speed + Seed * 1.5)
Seed = vertex.x × 123.456 + vertex.y × 789.012
```

### 噪声增强
```
noise_offset = (noise(time, position) - 0.5) × Strength × 0.3
final_offset = sin/cos_offset + noise_offset
```

### UV抖动（可选）
```
UV_offset_X = (noise(time × frequency, UV.y) - 0.5) × UV_strength
UV_offset_Y = (noise(UV.x, time × frequency) - 0.5) × UV_strength
```

## 💡 进阶使用

### 动态控制示例代码

```csharp
using UnityEngine;

public class JitterController : MonoBehaviour
{
    private Material jitterMaterial;
    
    void Start()
    {
        jitterMaterial = GetComponent<SpriteRenderer>().material;
    }
    
    // 设置抖动强度
    public void SetJitterStrength(float strength)
    {
        jitterMaterial.SetFloat("_JitterStrengthX", strength);
        jitterMaterial.SetFloat("_JitterStrengthY", strength);
    }
    
    // 根据生命值调整
    public void UpdateByHealth(float healthPercent)
    {
        // 生命值越低，抖动越强
        float strength = Mathf.Lerp(0.03f, 0.008f, healthPercent);
        SetJitterStrength(strength);
    }
}
```

### 平滑过渡

```csharp
IEnumerator TransitionJitter(float targetStrength, float duration)
{
    float start = jitterMaterial.GetFloat("_JitterStrengthX");
    float elapsed = 0f;
    
    while (elapsed < duration)
    {
        elapsed += Time.deltaTime;
        float t = elapsed / duration;
        float current = Mathf.Lerp(start, targetStrength, t);
        SetJitterStrength(current);
        yield return null;
    }
}
```

## 🎨 效果特点

### 视觉效果
- **顶点抖动**：整个Sprite产生微小的位置偏移
- **非同步**：每个顶点抖动相位不同，创造自然效果
- **连续性**：基于时间的平滑动画，不会突然跳跃
- **有机感**：噪声函数增强，避免机械感

### 适用场景
- ✅ 2D角色的Idle动画
- ✅ 恐怖游戏的不稳定效果
- ✅ 手绘风格游戏的线条抖动
- ✅ 背景物体的轻微摇晃（灯、树枝等）
- ✅ 受伤/中毒/异常状态的视觉反馈

---

## ⚠️ 注意事项

### 性能
- ✅ 顶点计算开销很小
- ✅ 适合移动平台
- ⚠️ 大量物体时考虑降低频率

### 使用建议
- 从小参数开始（0.008-0.01）
- X和Y频率设置不同值
- 速度不要超过3.0（会显得不自然）
- 材质实例 vs 共享材质的区别

### 兼容性
- ✅ Unity 2019.4+
- ✅ URP渲染管线
- ✅ Built-in渲染管线
- ✅ 支持透明度
